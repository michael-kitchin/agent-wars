A turn-based grand strategy game on a real-Earth hex map. Your opponents are large language models you choose through OpenRouter. Coding agents wrote the code; the story is told in the Agent Wars series in [*Standing Orders*](https://standingorders.substack.com).

## Downloads

| File | For |
| --- | --- |
| `agent-wars-2.8.0-windows-x64.zip` | Windows, x64 |
| `agent-wars-2.8.0-macos-arm64.zip` | macOS on Apple silicon |
| `agent-wars-2.8.0-linux-x64.tar.gz` | Linux, x64 |
| `SHA256SUMS.txt` | SHA-256 checksums for the three archives |

These are unsigned side-load builds, so Windows and macOS warn before the first launch.

- **Windows:** unzip, then run `Agent Wars v2.8.0.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, then open `Agent Wars v2.8.0.app`. If macOS blocks it, open **System Settings > Privacy & Security** and choose **Open Anyway**.
- **Linux:** extract the archive, then run `./agent-wars`. That launcher handles Chromium's sandbox when the archive can't keep `chrome-sandbox` owned by root. On Ubuntu 23.10 and later, where AppArmor blocks unprivileged user namespaces, it starts without the sandbox and says so.

To check a download, compare its SHA-256 with the line in `SHA256SUMS.txt`: `Get-FileHash <file>` in PowerShell, `shasum -a 256 <file>` on macOS, or `sha256sum -c --ignore-missing SHA256SUMS.txt` on Linux.

## Before you play

- **Bring your own OpenRouter key.** Start a match, open the **Command** tab, and open a commander's card. Paste that opponent's key, choose a model, and click **Start**. Each opponent has its own key. A new game fills only the first opponent from the key you used last. OpenRouter bills your account for the commanders' model calls. Without a key and a model on at least one commander the app still runs, **Start** stays off, and that opponent makes no model calls. The key stays on your computer and is sent only to OpenRouter ([SECURITY.md](https://github.com/michael-kitchin/agent-wars/blob/main/SECURITY.md)).
- **Map imagery needs an internet connection.** Map tiles come from Esri and OpenStreetMap.
- **Non-commercial use.** The app ships earth data under non-commercial terms, so the application as distributed is for non-commercial use. See [THIRD-PARTY-NOTICES.md](https://github.com/michael-kitchin/agent-wars/blob/main/THIRD-PARTY-NOTICES.md).

How a match plays is in [doc/how-to-play.md](https://github.com/michael-kitchin/agent-wars/blob/main/doc/how-to-play.md).

## What's in 2.8.0

Matches can have two to four sides. The 2.6.0 layout is unchanged.

- **One commander per AI side.** Each card has its own API key, model, reasoning effort, and doctrine. Adding an opponent copies the previous opponent's commander settings, not its home. Observe only gives every side to a commander.
- **Start and Stop.** They sit at the top of the Command tab and apply to every commander. **Start** stays off until at least one commander has both a key and a model. Starting a match with no model selected asks first: "Start the game with no models set?"
- **Ready while commanders plan.** The button reads `AI: MM:SS (xN)`. N is how many commanders are still planning.
- **Messages.** Opponent messages share one dialog, with a tab per AI side. A tab starts disabled and turns on when that side sends a message.
- **Turn update.** Losses are listed by side, with each unit's origin flag, then the hex-capture lines and the other updates.
- **How the match ends.** Both maps offer Deathmatch, the default, which has no turn limit, and Most city hexes at turn limit, which lasts 20, 30, 40, or 50 turns.

## Known limits

- There is no player-facing save slot or load list yet. SQLite keeps the match in progress on disk.
- Settings, Help, Save game, Load game, How to play, the Build and Forces tabs, and Replay on a turn report are placeholders in this version.
- On macOS, Quit closes the window and the app stays in the dock.
- The macOS build is for Apple silicon only, and it hasn't been opened on a Mac yet, so its first-launch steps are untested.
- Model quality varies. A model without tool calls plays without the planning tools.
- This is mostly a personal R&D project. Issues and pull requests are welcome; responses and acceptance are best-effort. Security reports go through the repository's **Security** tab.
