A turn-based grand strategy game on a real-Earth hex map. Your opponents are large language models you choose through OpenRouter. Coding agents wrote the code; the story is told in the Agent Wars series in [*Standing Orders*](https://standingorders.substack.com).

## Downloads

| File | For |
| --- | --- |
| `agent-wars-2.9.0-windows-x64.zip` | Windows, x64 |
| `agent-wars-2.9.0-macos-arm64.zip` | macOS on Apple silicon |
| `agent-wars-2.9.0-linux-x64.tar.gz` | Linux, x64 |
| `SHA256SUMS.txt` | SHA-256 checksums for the three archives |

These are unsigned side-load builds, so Windows and macOS warn before the first launch.

- **Windows:** unzip, then run `Agent Wars v2.9.0.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, then open `Agent Wars v2.9.0.app`. If macOS blocks it, open **System Settings > Privacy & Security** and choose **Open Anyway**.
- **Linux:** extract the archive, then run `./agent-wars`. That launcher handles Chromium's sandbox when the archive can't keep `chrome-sandbox` owned by root. On Ubuntu 23.10 and later, where AppArmor blocks unprivileged user namespaces, it starts without the sandbox and says so.

To check a download, compare its SHA-256 with the line in `SHA256SUMS.txt`: `Get-FileHash <file>` in PowerShell, `shasum -a 256 <file>` on macOS, or `sha256sum -c --ignore-missing SHA256SUMS.txt` on Linux.

## Before you play

- **Bring your own OpenRouter key.** Start a match. The console on the right starts collapsed; click **Command** and open a commander's card. Paste that opponent's key, choose a model, and click **Start**. Each opponent has its own key. A new game fills only the first opponent from the key you used last. OpenRouter bills your account for the commanders' model calls. Without a key and a model on at least one commander the app still runs, **Start** stays off, and that opponent makes no model calls. The key stays on your computer and is sent only to OpenRouter ([SECURITY.md](https://github.com/michael-kitchin/agent-wars/blob/main/SECURITY.md)).
- **Map imagery needs an internet connection.** Map tiles come from Esri and OpenStreetMap.
- **Non-commercial use.** The app ships earth data under non-commercial terms, so the application as distributed is for non-commercial use. See [THIRD-PARTY-NOTICES.md](https://github.com/michael-kitchin/agent-wars/blob/main/THIRD-PARTY-NOTICES.md).

How a match plays is in [doc/how-to-play.md](https://github.com/michael-kitchin/agent-wars/blob/main/doc/how-to-play.md).

## What's in 2.9.0

- **Save.** Save game… in the game menu writes the match to an `.agentwars` file while you are giving orders, including during a battle. You cannot save while a turn or battle beat is still resolving, or after the match is over. The last five turn starts are kept automatically.
- **Load.** Load game… is in that menu and on the New game bar. If a match is still going, the game asks before it replaces that match. A file from another version of Agent Wars cannot be opened.
- **What stays on this computer.** The file does not include API keys, remembered commanders, or the app-wide model and reasoning choices. Each side's model, reasoning effort, and doctrine stay in the file.

## Known limits

- There is no in-app list of saves, and no turn replay.
- Settings, Help, How to play, the Build and Forces tabs, and Replay on a turn report are placeholders in this version.
- On macOS, Quit closes the window and the app stays in the dock.
- The macOS build is for Apple silicon only, and it hasn't been opened on a Mac yet, so its first-launch steps are untested.
- Model quality varies. A model without tool calls plays without the planning tools.
- This is mostly a personal R&D project. Issues and pull requests are welcome; responses and acceptance are best-effort. Security reports go through the repository's **Security** tab.
