A turn-based grand strategy game on a real-Earth hex map. Your opponents are large language models you choose through OpenRouter. Coding agents wrote the code; the story is told in the Agent Wars series in [*Standing Orders*](https://standingorders.substack.com).

## Downloads

| File | For |
| --- | --- |
| `agent-wars-2.21.1-windows-x64.zip` | Windows, x64 |
| `agent-wars-2.21.1-macos-arm64.zip` | macOS on Apple silicon |
| `agent-wars-2.21.1-linux-x64.tar.gz` | Linux, x64 |
| `SHA256SUMS.txt` | SHA-256 checksums for the three archives |

These are unsigned side-load builds, so Windows and macOS warn before the first launch.

- **Windows:** unzip, then run `Agent Wars v2.21.1.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, then open `Agent Wars v2.21.1.app`. If macOS blocks it, open **System Settings > Privacy & Security** and choose **Open Anyway**.
- **Linux:** extract the archive, then run `./agent-wars`. That launcher handles Chromium's sandbox when the archive can't keep `chrome-sandbox` owned by root. On Ubuntu 23.10 and later, where AppArmor blocks unprivileged user namespaces, it starts without the sandbox and says so.

To check a download, compare its SHA-256 with the line in `SHA256SUMS.txt`: `Get-FileHash <file>` in PowerShell, `shasum -a 256 <file>` on macOS, or `sha256sum -c --ignore-missing SHA256SUMS.txt` on Linux.

## Before you play

- **Bring your own OpenRouter key.** Start a match. The console on the right starts collapsed; click **Command** and open a commander's card. Paste that opponent's key, choose a model, and click **Start**. Each opponent has its own key. A new game fills only the first opponent from the key you used last. OpenRouter bills your account for the commanders' model calls. Without a key and a model on at least one commander the app still runs, **Start** stays off, and that opponent makes no model calls. The key stays on your computer and is sent only to OpenRouter ([SECURITY.md](https://github.com/michael-kitchin/agent-wars/blob/main/SECURITY.md)).
- **The map is in the download.** Shaded relief is packed with the app, so the map does not use a tile server. The first time a regional map is shown, its tiles unpack on this computer. A commander's model calls still need an internet connection.
- **Non-commercial use.** The app ships earth data under non-commercial terms, so the application as distributed is for non-commercial use. See [THIRD-PARTY-NOTICES.md](https://github.com/michael-kitchin/agent-wars/blob/main/THIRD-PARTY-NOTICES.md).
- **Saves.** A save from 2.12.0 through 2.21.0 still opens. A save from 2.10.0 or earlier will not load in 2.21.1. A save with no beat limit is Unlimited.

How a match plays is in [doc/how-to-play.md](https://github.com/michael-kitchin/agent-wars/blob/main/doc/how-to-play.md).

## What's in 2.21.1

### Beat limit

- **A new dropdown.** Game Options has a Beat limit dropdown beside AI-only battles, under the Victory row. It offers 20, 30, 40, or 50 beats (`AI_ONLY_BEAT_LIMIT_OPTIONS`, the same list as Turn limit) or Unlimited. It is set to 30 (`DEFAULT_AI_ONLY_BEAT_LIMIT`) each time the dialog opens. Choosing None under AI-only battles disables it and shows Unlimited. Picking a battle mode again brings back your last choice. Start stores it as the match row `ai_only_beat_limit`. Changing the dropdown later does not touch a match that is already running.
- **When a battle stops.** An AI-only battle now ends after the beat that completes the limit, once that beat's orders resolve (`aiOnlyBeatLimitReached`). `applyAiOnlyTacticalBeat` checks the other endings first: a wiped side, then three beats with no applied order, then both commanders leaving after five beats. Any of those still wins on the limit beat. Unlimited never ends a battle this way.
- **Same as Exit Battle.** A battle that reaches its limit leaves the way Exit Battle does. Each side's strategic unit is destroyed when fewer than half of the battle units it fielded survive. Exactly half survives.
- **The notice.** The result reads "The battle reached its maximum of N beats.", where N is the beats completed. While "Start the next turn when every commander is ready" is off, it waits for Ok, which returns to the world map and does not press Ready. While it is on, other AI-only endings leave the battle with no dialog. A beat-limit ending shows its notice for 3 seconds (`AI_ONLY_BEAT_LIMIT_NOTICE_MS`) after that beat's playback, then the next strategic turn starts. Ok skips the wait and starts that turn.
- **Older saves.** A save with no `ai_only_beat_limit` row reads as Unlimited (`aiOnlyBeatLimitFromStored`), so a battle in a match saved by 2.21.0 or earlier runs without a cap.

### Observing

- **All sides.** While you are observing and View as is "All sides, no fog", Production and Forces now add up every side still playing. Before, both read zero in that view. Production sums every one of those sides' cities. Forces counts their fielded units against the game-size cap times the number of sides still playing (`scaleCapsForSides`). A knocked-out side is left out of both. The tips change to match: "The production every side's cities can add each turn, added together." and "Units every side still playing has fielded, out of the most this game size allows them". A named side still shows that side alone.

### New game

- **Game Options.** Fog of war, Sight cues, and Auto-start AI now sit in their own Other section under Rules, in three equal columns, in that order. The Game Options button's tip now names AI-only battles, beat limit, and Sight cues along with the rest.

## Known limits

- There is no in-app list of saves, and no turn replay.
- Settings, Help, How to play, the Build and Forces tabs, and Replay on a turn report are placeholders in this version.
- On macOS, Quit closes the window and the app stays in the dock.
- On the world map, outside a battle, a route or a played-back move that crosses the 180° meridian runs off the edge of the map. The destination hex is drawn on the opposite edge.
- The macOS build is for Apple silicon only, and it hasn't been opened on a Mac yet, so its first-launch steps are untested.
- Model quality varies. A model without tool calls plays without the planning tools.
- This is mostly a personal R&D project. Issues and pull requests are welcome; responses and acceptance are best-effort. Security reports go through the repository's **Security** tab.
