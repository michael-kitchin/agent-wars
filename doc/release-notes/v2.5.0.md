The first public release of Agent Wars, a turn-based grand strategy game on a real-Earth hex map. Your opponent is a large language model you choose through OpenRouter. Coding agents wrote the code; the story is told in the Agent Wars series in [*Standing Orders*](https://standingorders.substack.com).

| File | For |

| `agent-wars-2.5.0-windows-x64.zip` | Windows, x64 |

| `agent-wars-2.5.0-linux-x64.tar.gz` | Linux, x64 |
| `SHA256SUMS.txt` | SHA-256 checksums for the three archives |

These are unsigned side-load builds, so Windows and macOS warn before the first launch.

- **Windows:** unzip, then run `Agent Wars v2.5.0.exe`. If SmartScreen stops it, choose **More info**, then **Run anyway**.
- **macOS:** unzip, then open `Agent Wars v2.5.0.app`. If macOS blocks it, open **System Settings > Privacy & Security** and choose **Open Anyway**.
- **Linux:** extract the archive, then run `./agent-wars`. That launcher handles Chromium's sandbox when the archive can't keep `chrome-sandbox` owned by root.

To check a download, compare its SHA-256 with the line in `SHA256SUMS.txt`: `Get-FileHash <file>` in PowerShell, `shasum -a 256 <file>` on macOS, or `sha256sum -c --ignore-missing SHA256SUMS.txt` on Linux.

## Before you play

- **Bring your own OpenRouter key.** Paste it on the Model tab, choose a model, and click **Run**. OpenRouter bills your account for the opponent's model calls. Without a key the app still runs, but the opponent makes no model calls. The key stays on your computer and is sent only to OpenRouter ([SECURITY.md](https://github.com/michael-kitchin/agent-wars/blob/main/SECURITY.md)).
- **Map imagery needs an internet connection.** Map tiles come from Esri and OpenStreetMap.
- **Non-commercial use.** The app ships earth data under non-commercial terms, so the application as distributed is for non-commercial use. See [THIRD-PARTY-NOTICES.md](https://github.com/michael-kitchin/agent-wars/blob/main/THIRD-PARTY-NOTICES.md).

How a match plays is in [doc/how-to-play.md](https://github.com/michael-kitchin/agent-wars/blob/main/doc/how-to-play.md).

## What's in 2.5

- **The global game.** The whole world at H3 resolution 1, with fog of war, an economy, air power, sealift, and simultaneous turns.
- **Tactical battles.** Optional zoomed-in fights, three H3 resolutions finer, when forces contest a strategic hex. The model plays those too.
- **The regional game (new).** 23 regional maps drawn from UN subregions, at strategic resolution 2 or 3. Each side picks a side group of provinces, turns are one week, and each map has its own economy.
- **Four optional bonuses (new).** Origin, terrain, weather, and tech, each Off, Low, or High. Units carry a birth area and a flag, monthly climate weather sets each hex's conditions, and a unit's tech level follows the urban count where it was born.
- **d20 combat and terrain rules (new).** Hit numbers have a floor of 2 and a cap of 17. Armor that enters rugged, arctic, or city hexes stops there, and city and rugged hexes add strategic cover.
- **The opponent (new).** Structured output, a reasoning-effort selector, and a consultation round that adapts to each model's tool support.
- **A new look (new).** A UI facelift, dice chips and destroyed-unit playback during resolution, weather and tech icons on the map, and a new-game dialog with a live map preview.

## Known limits

- There is no player-facing save slot or load list yet. SQLite keeps the match in progress on disk.
- The macOS build is for Apple silicon only, and it hasn't been opened on a Mac before this release, so its first-launch steps are untested.
- Model quality varies. A model without tool calls plays without the planning tools.
- This is a personal R&D project. It doesn't take issues or pull requests; security reports go through the repository's **Security** tab.
